# 🍺 Beer Counter

A clean, minimalist web app built to practice core HTML, CSS, and JavaScript concepts.

## ✨ Features
- **Increment:** Easily count each beer with a single click.
- **Save:** Keep track of previous entries and sessions.
- **Responsive Design:** Adapts smoothly to both desktop and mobile screens.

## 🛠️ Technologies Used
- HTML5
- CSS3 (Flexbox & responsive units)
- JavaScript (DOM manipulation)
